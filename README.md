# Steam Deck Keyboard

If you're unlucky enough to meet all three conditions below, this mod is for you:

1. You own a Steam Deck and insist on playing Minecraft Java Edition on it
2. You don't have Controlify or Moon Control mod installed (which include built-in keyboards), or they crash on your setup
3. Steam's built-in virtual keyboard works intermittently, often failing when you need it

It may have some legacy quirks, but it works and runs smoothly with no conflicts across my 100+ mod setup. Feel free to try it, modify it, or do whatever you want with it. Attribution is appreciated but not required.

---

如果你和我一样，倒霉到符合下面三个条件，那么这个 mod 是写给你的：

1. 有一台 steamdeck，并且非要在上面玩 Minecraft Java 版
2. 没有装 controlify 手柄模组或 Moon control 模组（自带键盘功能），或者是像我一样闪退无法使用
3. Steam 自带的虚拟键盘时好时坏，经常无法使用

它可能有一点历史遗留问题，但是可以使用，并且很流畅，没有与我的 100 个 mod 冲突，所以你可以试试，或者自己进行修改，完全 OK，你可以随意使用它，如果能标明出处就更好了
